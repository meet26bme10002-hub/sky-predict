# Project Statement

## Problem Statement
Weather conditions vary from day to day and depend on several environmental factors. This project develops a simple machine-learning system that uses historical weather observations to estimate temperature.

## Scope
The project covers weather data loading, preprocessing, visualization, machine-learning model training, evaluation, and temperature prediction.

## Target Users
Students, beginners learning machine learning, teachers, and academic evaluators.

## High-Level Features
1. CSV weather data loading
2. Data cleaning
3. Weather visualization
4. Linear Regression model training
5. Model evaluation
6. Temperature prediction
7. Input validation
